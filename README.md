# Map Poster Full Repo
This repository bundles all source code of the project work for the Cloud Computing II course.

## Project Structure
1. **submodule /map-poster-web-app** \
   contains the source of the web app including the API, written with Next.js
2. **/terraform** \
   contains the Terraform scripts used for provisioning the Azure infrastructure and MongoDB Atlas cluster
3. **/ansible** \
   contains the Ansible playbook which is used to set up the VMs after their creation to run the containerized web app

## How to execute

### Prerequisites
When new changes are pushed onto the main branch of the [Web App Submodule](https://github.com/Snenz/map-poster-web-app), a GitHub Action will run and build a docker image that will be uploaded to the repository's container registry. This image will be used by the Ansible playbook.

### Terraform
To provision the ressources the Terraform scripts can be executed like this.

```bash
cd terraform/
terraform init
terraform apply
```

Before being able to run the scripts, a `terraform.tfvars` file must be provided in the `/terraform` directory. `terraform.tfvars.example` serves as a preset and shows which variables must be set.

### Ansible
After provisioning the ressources an `inventory.ini` and `.env.production` file will be generated by Terraform in the `/ansible` directory. `.env.production` will contain the secret database connection parameters. \
Furthermore, the Ansible playbook must be provided with the two files `ghcr_secrets.yml` and `ddns_secrets.yml` which provide secrets for accessing the GitHub Container Registry and the DynDNS provider's API. The `*.example` files show what they must contain. \
Finally, the playbook can be executed like this.

```bash
cd /ansible
ansible-playbook -i inventory.ini main_playbook.yml
```
